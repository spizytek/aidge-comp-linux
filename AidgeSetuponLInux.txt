Vivado 2026.1 on Ubuntu 26.04: libncurses.so.5 missing:
Vivado 2026.1 was built against libncurses.so.5 and libtinfo.so.5. Current Ubuntu ships only version 6 (libncurses.so.6, libtinfo.so.6), and the libncurses5 package is no longer in the repos.

Fix:
Symlink the version 5 names to the installed version 6 libraries:
command:
sudo ln -s /lib/x86_64-linux-gnu/libncurses.so.6 /lib/x86_64-linux-gnu/libncurses.so.5
sudo ln -s /lib/x86_64-linux-gnu/libtinfo.so.6 /lib/x86_64-linux-gnu/libtinfo.so.5

NOTE:
Vivado asks for libncurses.so.5. That file didn’t exist, so it failed. After the link was created, Vivado finds libncurses.so.5, Linux redirects it to the real libncurses.so.6, and the program loads normally.

This works here because version 6 of ncurses stays compatible with what Vivado needs from version 5.

Two independent problems, in order of appearance:
sqrt has no functional unit, hard stop at module allocation. Needs the operation replaced with *, +, / (all mapped), e.g. Newton–Raphson, or moved to the CPU via CPU().

In this shipped PandA 0.9.8 image, sqrt cannot be synthesized. Not "no sqrt unit exists" — a unit is declared (fp_sqrt_FU, fp_sqrtf_FU) — but the IR operation never binds to it, so module allocation fails.

13.4 MiB of weights as internal memory will not fit 630 KB, regardless of #1. Needs streaming from DDR (demo/bram_to_ddr) or a much smaller layer.






LOAD FPGA.bin INTO PL before running the cpu code with this script:

cat > ~/mytest/load_fpga.sh <<'EOF'
#!/bin/bash
set -e

if [ $# -lt 1 ]; then
    echo "Usage: $0 <bitstream.bin>" >&2
    exit 1
fi

SRC="$1"
DST=/lib/firmware/fpga_swapped.bin

if [ ! -f "$SRC" ]; then
    echo "ERROR: bitstream not found: $SRC" >&2
    exit 1
fi

python3 - "$SRC" "$DST" <<'PY'
import sys
src, dst = sys.argv[1], sys.argv[2]
d = open(src, 'rb').read()
o = bytearray(len(d))
for i in range(0, len(d), 4):
    o[i:i+4] = d[i:i+4][::-1]
open(dst, 'wb').write(o)
PY

echo 0 > /sys/class/fpga_manager/fpga0/flags
echo fpga_swapped.bin > /sys/class/fpga_manager/fpga0/firmware

STATE=$(cat /sys/class/fpga_manager/fpga0/state)
echo "FPGA manager state: ${STATE}"
if [ "${STATE}" = "operating" ]; then
    echo "Successively done uploading FPGA.bin to PL!!"
else
    echo "ERROR: FPGA load failed (state: ${STATE})" >&2
    exit 1
fi
EOF
chmod +x ~/mytest/load_fpga.sh
